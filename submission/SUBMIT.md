commit is created. Submit that exact source commit:

1. Open https://www.joinbuilders.org/buildathon/tracks/shopping-sessions and sign
   in to the correct team.
2. Use public repository https://github.com/akshayagg18/shopping-cl and the exact
  40-character `scorer_commit` from READY.json.
3. Submit once. The candidate has passed local fixtures/dev/reference/fuzz/20M
   checks and a static Docker rebuild; there is no reason to spend an attempt
   on a speculative variant.
4. Wait for the actual validation and score receipt. Record runtime, rank,
   scorer version and feedback; a GitHub push is not a scoring receipt.
